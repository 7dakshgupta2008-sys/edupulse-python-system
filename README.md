# Student Academic Management System (Cross-Laptop Ready)

A complete Student Academic Management System built using **Python (Flask), C, Java, HTML5, CSS3, XAMPP MySQL, and Interactive Student AI Chatbot**.

---

## 💻 How to Run on ANOTHER Laptop (Step-by-Step)

When copying the project to a new laptop, follow these simple steps:

### Step 1: Open Project in VS Code
Open VS Code ➔ Open Folder: `edupulse-python-system`

### Step 2: Run 1-Click Setup
Open VS Code Terminal (`Ctrl + ~`) and run:
```bash
python setup.py
```
*(This automatically installs dependencies and seeds XAMPP MySQL if running on the new laptop!)*

### Step 3: Start Application
Run:
```bash
python app.py
```
Open browser to:  
👉 **http://localhost:5000/login**
